# 真实授权外部因子验收

## 当前状态

截至 2026-08-25，真实验收入口和异步数据充分性预检已经实现，但尚未取得符合契约的用户授权因子 CSV。当前开发运行库已迁移为 schema v18，候选版本、授权数据集、观测、绑定和外部研究归档仍均为 0；库内现有 Tick/K 线不能冒充外部授权因子。项目目录与用户下载目录中也未发现符合 `timestamp,symbol,value` 契约的文件。

## 显式验收流程

1. 用户确认文件授权范围、来源版本和可审计来源引用。
2. 先登记并冻结候选版本，其 `factorKey` 必须与 CSV 导入身份一致。
3. 显式选择 CSV，执行异步预览；确认内容 SHA-256 后事务导入并绑定。
4. 为候选、数据集和收益周期执行异步预检。预检逐标的检查无陈旧 `BacktestDatasetIdentity`、`raw_tick_cache_v1` 完成 Bar 和观测时间覆盖，不写归档、不访问 Provider。
5. 只有预检完全通过才开放研究。成功结果进入 schema v17 不可变归档；历史加载只读 SQLite。

## 验收证据

需记录授权说明、数据集/候选/归档摘要、覆盖时段、标的与时刻数、缺腿清单、预检耗时、研究参数及结果身份。独立时期应与候选提出和冻结时间关系清晰；fixture、派生示例和同一样本调参结果不得标记为前瞻证据。统计结果只代表研究样本，不构成投资建议。

当前待用户提供真实授权文件；项目不会自动扫描目录、下载替代数据或把网络行情转换成“授权外部因子”。
