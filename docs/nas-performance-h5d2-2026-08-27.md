# NAS 取消与重启恢复 H5D.2 验收（2026-08-27）

## 范围与结论

H5D.2 收紧 NAS 同步队列和同步后回测目录准备的取消/恢复边界。本轮没有连接 NAS，也没有访问行情 Provider；真实授权 100 标的数据库仅作为本地、可删除的进程中断副本。500/5207 标的继续延期。

完成项：

- 下载 requestId 使用显式门控；取消后迟到的 progress/result 不再因缺失映射默认落到队列第 0 项。
- 跨进程恢复把持久化 `ready` 项视为可继续工作，既有 `succeeded` 项保持成功且不会重复派发。
- `BacktestDatasetService` 在标的、逐日和逐 Tick 流式聚合边界检查原子取消；取消中的当前项不伪报成功或失败。
- Controller 结束或取消批次时一次性关闭活动下载代次；SQLite schema 保持 v18。

## 100 标的进程中断证据

从 H5C 保留基线复制隔离数据库，以 90 秒周期、100 根目标启动 100 标的准备；运行约 2.1 秒后强制终止该受控探针。中断时没有生成完成报告，但已提交的逐标的事务留在数据库中。对同一副本重新启动后：

- 目录读取 4 ms，发现 179 个身份（原有 100 个 60 秒身份，以及本轮已提交的 79 个 90 秒身份）；
- 90 秒准备共 146 ms，复用 79 个已提交缓存，只重建剩余 21 个；
- SMA 100 根回测 216 ms，100/100 成功、0 失败；
- 证据为 `artifacts/nas-performance-h5d2-2026-08-27/recovered.json`。

这证明本地逐标的事务在进程中断后可复用，并且重启不会把已完成项全部重做；它不证明真实网络下载可在任意字节位置恢复。
111,824,896 字节的隔离数据库副本在结果确认后已删除，只保留 JSON 与空 stdout/stderr；基线数据库未修改。
