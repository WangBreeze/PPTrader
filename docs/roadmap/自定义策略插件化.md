# 自定义策略插件化（加载 / 卸载）

> 状态：设计确认，核心已实现（`CustomStrategyRuntimeManager`）。
> 目标：让「通过校验的自定义策略」像插件一样可加载、激活、停用、卸载，全程不重启应用。

## 1. 背景与现状

自定义策略以受限 JSON DSL（`CustomStrategyDefinition`）持久化在 SQLite，编译产物为
`CompiledCustomStrategy`。阶段 C 已打通「编译 → 模拟执行」链路：

- `CustomExecutionStrategy`：消费 Candle、按 DSL 规则产出 `TradeSignal` 的运行时（QMutex 线程安全）。
- `StrategyEngine::addStrategy/removeStrategy/setStrategyEnabled`：运行时增删与启停。
- `CustomStrategyValidator`：`executionScope` 支持 `backtest_only` / `mock_execution`。

阶段 C 早期的 `enable/disableCustomStrategyExecution` 只是「编译 + 加入引擎 / 移除引擎」的二态
开关，缺少中间态与统一生命周期，因此抽取为下述管理器。

## 2. 两种「插件」形态对比

| 维度 | A. DSL 策略单元（已实现） | B. C++ Qt Plugin（QPluginLoader） |
| --- | --- | --- |
| 载体 | SQLite 中的 JSON DSL 定义 | `.dll`/`.so`，实现 `Strategy` 接口 |
| 第三方扩展 | 受限（白名单指标/算子） | 完全自由（任意 C++） |
| 安全边界 | 天然受 DSL 校验约束 | 需签名/沙箱/审计，风险高 |
| 依赖隔离 | 编译产物仅依赖稳定接口 | 需 ABI 版本锁定 |
| 热插拔 | 支持（本方案） | 支持（但卸载需处理活跃实例） |
| 适用阶段 | 当前（策略研究/回测/模拟执行） | 未来（可信第三方策略市场） |

**结论**：当前采用 A（DSL 策略单元），因为它复用既有 DSL 校验/编译链路、无 ABI/安全负担，
且已满足「模拟执行」目标；B 作为演进方向保留，待「第三方策略」需求明确后再引入。

## 3. 生命周期状态机

```
Unloaded ──load──▶ Loaded ──activate──▶ Active
   ▲                 ▲                     │
   │                 └────deactivate───────┘
   └────────────────unload─────────────────┘
```

- `load(definition, instrument)`：校验 scope、编译并缓存 `CompiledCustomStrategy`，不进入引擎。
- `activate(strategyId)`：实例化 `CustomExecutionStrategy` 并 `StrategyEngine::addStrategy`。
- `deactivate(strategyId)`：`removeStrategy`（释放运行时），保留编译产物，可再次 `activate`。
- `unload(strategyId)`：释放全部记录，回到 `Unloaded`。

状态对外以 `plugins()`（`QVariantList`）暴露给 QML：`strategyId/name/version/symbol/state/stateName/error`。

## 4. 依赖隔离与稳定接口

管理器只依赖稳定接口，不与 `TradingController` 内部实现耦合：

- `StrategyEngine`（`addStrategy/removeStrategy`）
- `CustomStrategyCompiler` → `CompiledCustomStrategy`
- `CustomExecutionStrategy`（消费 `CompiledCustomStrategy` + `Instrument`）

执行参数（审批/冷却/仓位预算）仍走 `StrategyExecutionConfig`，不进 DSL，保持与阶段 C 决策一致。

## 7. 第三方 C++ 插件（已实现）

- 接口 `src/plugin/StrategyPluginInterface.h`：`pluginApiVersion/pluginId/pluginName/pluginVersion/
  pluginDescription` + `createStrategy(config, parent)`；稳定 IID `pp.StrategyPlugin/1.0`。
- 管理器 `src/plugin/StrategyPluginManager`：`scan()`（.dll/.so + manifest 状态）、`load()`（清单
  SHA-256 校验 → `QPluginLoader` → `qobject_cast` → ABI 版本校验）、`unload()`；`expectedSha256`/
  `computeFileSha256` 可测静态方法。
- 清单 `plugins.manifest`：目录级白名单 `{file, sha256}`，防篡改的完整性校验（非作者签名）。
- 示例插件 `examples/sample_strategy_plugin/`：MODULE 库生成 `.dll`，自带 `SampleThresholdStrategy`。
- 宿主接线：`TradingController::strategyPluginScan/loadStrategyPlugin/unloadStrategyPlugin/
  loadedStrategyPlugins/activateStrategyPluginStrategy/setStrategyPluginDirectory`，默认目录
  `应用目录/strategies`。
