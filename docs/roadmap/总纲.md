# PPTrader 总纲

## 产品目标

PPTrader 是一个先覆盖 A 股、再扩展至美股、外汇和加密货币的量化研究与模拟交易平台。首期只承诺沪深 A 股；北交所作为 A 股扩展项，不阻塞主线。所有大模型建议、策略和因子结论必须先经过可复现回测与风险检查，不能直接形成实盘指令。

## 架构原则

- **统一核心，市场适配。** `InstrumentId` 采用 `market:assetClass:symbol`，如 `CN-SSE:equity:600519`、`US-NASDAQ:equity:AAPL`、`FX:spot:EURUSD`、`CRYPTO-BINANCE:spot:BTC-USDT`。
- **规则可注入。** `MarketRules` 描述时区、交易日历、T+1、最小价格变动、整手、涨跌停、费税、杠杆和卖空规则。回测与下单不得硬编码 A 股规则。
- **数据源可替换。** Provider 只负责拉取与归一化；行情、K 线、公司行动、因子和快照进入统一存储与查询接口。
- **研究与执行分离。** 策略产生信号，回测模拟成交；模拟/实盘执行需经过独立的风控、审批和账户模块。
- **QML 只经控制器。** 页面只使用 `TradingController` 暴露的模型与命令，不能直接访问 Provider、SQLite 或策略对象。

## 路线图

1. A 股任意品种切换与内置策略回测。
2. A 股自定义策略回测。
3. A 股任意组合横截面研究。
4. A 股大模型辅助与量化因子回测。
5. 复用统一核心，依次接入美股、外汇、加密货币。

截至 2026-08-14，路线 1 的任意沪深 A 股、四项内置策略、参数配置、异步任务、权益曲线、成交明细与归档链路已完成；阶段 8A–9C 已建立 Tick 事实、任意周期派生、受控导入与盘中增量。路线 2 已具备版本化 JSON DSL、自定义指标、严格本地回测和向导第 3 步，但八步向导、模拟执行审批与通知仍在后续计划。路线 3 已交付独立多品种矩阵和固定权重共享资金组合 v1；真实 500/5207 份装载、策略信号调仓和组合级风险未完成。NAS 节点继续只服务用户显式选择的数据，不扫描全仓、不保存 SSH 凭据，也不自动下载或运行回测。

当前并行主线仍由 `docs/roadmap/图表存储与行情10A-10F.md`、`docs/roadmap/历史Tick回测与NAS数据路线图.md` 和 `docs/roadmap/自定义策略向导后续阶段.md` 管理。新增方向「多股自定义回测（单只 → 多股横截面）」由 `docs/roadmap/多股自定义回测.md` 管理：阶段 1（`PortfolioExecutor` 抽取、`AlignedBarSeries` 对齐帧序列）与阶段 2（DSL v3、`CrossSectionalIndicatorRuntime`、`CrossSectionalCustomStrategy`、`CrossSectionalBacktestEngine`）已完成，阶段 3（服务 + UI 对接）待实施。H2 内容级事实指纹、自定义策略预览严格限源和 H3C.4 观测日并集估值已于 2026-08-14 完成；下一批验收重点是 NAS 并发乱序/取消迟到响应测试、10F 四小时以上长稳、NAS H4 真实节点故障/吞吐验证，以及向导后续步骤。500 与 5207 档真实写库按用户决定延期。实时免费分钟行情与历史 Tick 回测保持独立，SQLite 只放本机，NAS 只通过服务接口提供原始历史数据。

每阶段必须完成数据质量、异常状态、Qt Test、QML lint、人工运行验证及项目文档更新后才进入下一阶段。
