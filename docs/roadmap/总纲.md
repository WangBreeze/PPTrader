# PPTrader 总纲

## 产品目标

PPTrader 是一个先覆盖 A 股、再扩展至美股、外汇和加密货币的量化研究与模拟交易平台。首期只承诺沪深 A 股；北交所作为 A 股扩展项，不阻塞主线。所有大模型建议、策略和因子结论必须先经过可复现回测与风险检查，不能直接形成实盘指令。

## 架构原则

- **统一核心，市场适配。** `InstrumentId` 采用 `market:assetClass:symbol`，如 `CN-SSE:equity:600519`、`US-NASDAQ:equity:AAPL`、`FX:spot:EURUSD`、`CRYPTO-BINANCE:spot:BTC-USDT`。
- **规则可注入。** `MarketRules` 描述时区、交易日历、T+1、最小价格变动、整手、涨跌停、费税、杠杆和卖空规则。回测与下单不得硬编码 A 股规则。
- **数据源可替换。** Provider 只负责拉取与归一化；行情、K 线、公司行动、因子和快照进入统一存储与查询接口。
- **研究与执行分离。** 策略产生信号，回测模拟成交；模拟/实盘执行需经过独立的风控、审批和账户模块。
- **QML 只经控制器。** 页面只使用 `TradingController` 暴露的模型与命令，不能直接访问 Provider、SQLite 或策略对象。

## 路线图

1. A 股任意品种切换与内置策略回测。
2. A 股自定义策略回测。
3. A 股任意组合横截面研究。
4. A 股大模型辅助与量化因子回测。
5. 复用统一核心，依次接入美股、外汇、加密货币。

路线 1 的任意沪深 A 股、四项内置策略、参数配置、异步任务、权益曲线和成交明细功能链路已完成；主页已拆分实时、本地回测和 legacy 研究品种。阶段 7B 已完成回测归档；阶段 8A–8D 已完成 TickData 流式解析、受控多日导入、交易日历、覆盖恢复和 Scene Graph K 线查询；阶段 9A 将逐笔成交保存为 SQLite 事实并按需派生 1–86400 秒 K 线；阶段 9B 已用单代码单交易日的远端真实文件完成受控 SSH 传输、事务入库和主页双周期显示。NAS v1 节点现已作为虚拟机用户服务部署，内置与自定义策略只接受 `raw_tick_cache_v1` 数据集并在运行期保持离线。系统仍不扫描全量目录、不保存 SSH 凭据、不做全仓批量导入、逐笔回放或自动远端同步。路线 2 已完成版本化自定义策略、风控/T+1 和结果身份快照。历史数据主线与后续多日/多品种容量计划见 `docs/roadmap/历史Tick回测与NAS数据路线图.md`。

当前并行主线为 `docs/roadmap/图表存储与行情10A-10F.md` 和 `docs/roadmap/历史Tick回测与NAS数据路线图.md`：前者下一阶段是 10F 长稳验收，后者下一阶段是 H1 多日按需同步与容量基线。实时免费分钟行情与历史 Tick 回测是独立数据域；SQLite 只保留在本机，NAS 通过服务接口提供历史原始数据，不把 WAL 数据库文件直接放在网络共享上。

每阶段必须完成数据质量、异常状态、Qt Test、QML lint、人工运行验证及项目文档更新后才进入下一阶段。
