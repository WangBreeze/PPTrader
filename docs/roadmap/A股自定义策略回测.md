# A 股自定义策略回测

## 下一阶段（2026-09-07）

复用现有 DSL、八类内置基线和原始 Tick 样本外验证，按 [A 股选股与多指标策略研究](A股选股与策略组合研究.md) 推进多股基线、策略内日频选股／分时进场和多指标候选策略。多个指标组成一个策略；每个策略运行实例具有独立资金和持仓，不与其他策略共享账户。先修复 [工程审查](../strategy-research-review-2026-09-07.md) 中成交时序、T+1 和扫描真实性问题；本节是新增路线，不表示已有阶段测试能够证明盈利。回测执行仍默认原始 Tick，周期 K 需显式选择。

## 目标

让用户以安全、可版本化的方式定义 A 股回测策略，而不允许页面执行任意本机 C++、Python 或系统命令。

## 设计

首版采用受限策略 DSL，而非开放脚本运行时。DSL 由指标、比较、布尔条件、仓位规则和退出规则组成，例如：`SMA(10) 上穿 SMA(30) 且 RSI(14) < 70 时买入`。策略定义保存为 JSON，并具有唯一 ID、名称、版本、作者、参数 schema、市场范围和创建时间。

策略编译后生成受控的 `BacktestStrategy` 实例。可用指标首批限定 SMA、EMA、RSI、MACD、布林带、ATR、成交量均线；不允许网络、文件、反射、循环或动态加载。每次回测保存策略版本、参数、数据版本和 `MarketRules` 快照。

## 功能阶段

1. 策略 schema、持久化、校验器和只读策略详情。
2. 条件表达式与指标计算，包含预热期与缺失值规则。
3. 仓位、止盈止损、最大持仓天数和 A 股 T+1 校验。
4. 版本化策略接入异步回测，保存参数、规则与实际数据摘要。
5. 编辑器、参数表单、试运行和可读错误定位。
6. 回测对比：同品种、同区间最多对比三份已保存结果。

## 验收

- 非法表达式、越界参数、未知指标和未来函数使用必须拒绝。
- 相同策略版本、数据版本、参数和规则产生相同结果。
- 每项策略可导出为 JSON；导入必须先验证再写库。
- 自定义策略只能用于回测；进入模拟交易需单独审批，实盘自动执行不在本阶段范围。

## 当前实施状态

- 阶段 1 已完成：DSL v1 Schema、白名单校验、复杂度限制、不可变版本 SQLite 持久化、只读模型、控制器校验/保存/详情/导出接口及 Qt Test 已落地。
- 阶段 2 已完成：条件编译计划、运行参数规范化、七类增量指标、三值逻辑、预热期、缺失值和相邻有效 Bar 交叉语义均已实现并有确定性测试。
- 阶段 3 已完成：固定仓位比例、止损、止盈、最大持仓 Bar、A 股 T+1 锁存/跨日执行和不可变规则快照已实现；回测引擎已预留策略仓位预算与结果配置字段。
- 阶段 4 已完成：版本化定义通过专用控制器入口接入既有异步历史回测，结果包含策略版本、规范化参数、规则快照和实际 OHLCV 的 SHA-256 数据版本；引擎会再次校验实例身份。
- 阶段 5（界面阶段 6A）已完成：指标与策略页提供内置/自定义模式、版本列表、JSON 编辑、字段/路径错误、显式校验、不可变新版本保存、严格本地运行和可折叠结果身份。保存后按 strategyId/version 精确恢复选择。
- 自定义页面的唯一运行入口为 `runSelectedLocalCustomStrategyBacktest()`；只读取阶段 5A 选中的 SQLite 数据集，缺失或根数不足直接禁用，不调用历史 Provider。结果身份显示 strategyId、version、规范化参数和 SHA-256 dataVersion，切换版本后旧结果会明确标记不匹配。
- 当前定义状态 `backtest_ready`、`executable=true` 只表示允许受控历史回测；模拟/实盘订单入口仍不加载自定义策略。本页面不支持自由代码、LLM 生成策略或动态脚本。后续阶段可实现运行参数表单和同品种/同数据版本的多结果对比。
- 阶段 7A 已提供显式历史下载工作区。下载成功后 `localHistoryCatalog` 立即刷新，自定义策略可选择该数据集进行严格本地回测；选择数据集、刷新目录和运行严格本地回测本身仍不会触发 Provider。
- 阶段 7B 已完成内置与自定义回测结果归档。成功结果以不可变 result ID 事务化保存配置、规则、数据 SHA-256、摘要、权益和成交；应用重启只恢复摘要目录，用户显式加载后查看历史快照，不联网、不重跑，也不以当前定义或缓存改写身份。
- 2026-08-28 完成计算长稳补充：Release 单进程连续 15 分钟重复生成、校验和编译 168,482 份 `backtest_only` JSON DSL，并对每轮 5000 根执行 10 类白名单指标与自定义策略求值；失败 0、总轮次 p95 5.602 ms、预热后私有内存斜率 0.053 MiB/分钟、首末校验和一致。这里的“生成”是受控 DSL 文档构造，不是 LLM 或自由代码生成。
- 归档删除、自动保留期、版本引用保护、批量导出和阶段 6 的多结果对比仍未实现；当前本地归档持续保留。
