# A 股大模型辅助与量化因子回测

## 目标

建立可复现的 A 股因子研究能力，并将大模型限制为研究协作者：解释数据、生成候选因子/策略 DSL 草案、总结回测结果；不能直接下单或修改历史结果。

## 因子研究底座

- 因子注册表：ID、定义、参数、频率、适用股票池、依赖字段、缺失值与中性化规则。
- 数据版本：行情、复权、停牌、上市天数、行业分类和股票池均需有时间版本。
- 计算：横截面标准化、去极值、行业/市值中性化、分位数组合和换手率。
- 评估：IC/Rank IC、ICIR、分层收益、年化收益、最大回撤、换手、交易成本和容量提示。

## 大模型边界

大模型通过工具调用获得只读、脱敏、带数据版本的研究摘要。输出必须是结构化候选：因子定义、假设、数据依赖、风险和 DSL 草案。系统对候选进行语法、未来函数、数据可用性和风险校验后，才允许进入回测队列。模型不得访问凭据、执行本机命令、绕过审批或发出交易指令。

## 交付阶段

1. 因子/数据版本/结果存储模型。
2. 单因子 IC 与分层回测。
3. 多因子组合、交易成本和走样检查。
4. 大模型研究助手与候选审查流程。
5. 研究报告：输入、版本、参数、图表和结论可追溯。

## 阶段 12J–12S 范围（2026-08-23）

12J 先建立**策略内横截面因子暴露**基线，不提前宣称通用因子研究平台完成。因子只来自当前 DSL v3 的 `crossIndicators`，按每个对齐帧使用总体 Z-Score 标准化；目标暴露按目标权重加权，实际暴露按成交后持仓权重加权，现金暴露为零。用户可为一个已声明别名设置绝对目标暴露上限，超限时全部目标权重同比例缩小并留现金，不隐式重配、不执行因子中性化。存量持仓缺少当帧因子值时该帧标记不可测，不能沿用旧分数伪造覆盖。

12K 在此基础上新增 schema v14 不可变因子定义版本表，并将缺失值成对剔除、可配置分位数去极值、下一可用对齐帧 close-to-close 收益 IC/Rank IC 接入横截面回测与归档。当前只有注册目录计数和运行配置，没有因子版本编辑/删除管理 UI。

12L 保存有效 IC/Rank IC 双时间戳序列，按样本标准差计算非年化 ICIR，并固定输出因子值/代码稳定排序、帧内等权再跨帧等权的 Q1–Q5 收益和 Q5−Q1。方法版本与完整统计随归档身份恢复，QML 用 Canvas 绘制真实序列/分层空态。12M 继续在固定分层成员上计算相邻有效帧单边换手，并按用户明确输入的单边 bps 报告各层及 Q5−Q1 毛/净收益；首帧建仓排除，成本方法进入 v3 归档身份。

12N 增加研究用途的行业内因子去均值：成对剔除后先做全市场分位数去极值，再在满足最小组样本数的行业内减去因子均值；前向收益不调整，小组整组剔除。行业权重约束和研究中性化复用同一首帧日期不可变行业快照，`factor_research_v4` 保存策略、顺序、数据集、日期与快照 SHA-256。

12O 增加最多 4 个 SQLite 因子研究归档的显式只读对比。不同因子可以在周期、股票池、逐腿数据身份、对齐帧、预处理、收益、方法、成本与中性化身份一致时标为“受控可比”；身份不同只能标为“描述性对照”。操作不重跑、不联网、不合并结果，选择清单暂不持久化。

12P 为至少 20 个有效 IC/Rank IC 帧增加 Newey–West/Bartlett 相关稳健标准误、95% 正态近似区间与双侧 p 值，并对至少 9 帧做三个连续样本内区段的均值/符号稳定性报告。`factor_research_v5` 固定方法与阈值并随 SQLite 归档恢复；旧归档不补算。

12Q 从用户明确选择的不可变 SQLite 横截面归档生成单个自包含 Markdown 因子研究报告。报告固定带数据/策略/因子版本、方法、IC/Rank IC、HAC、三段稳定性、Q1–Q5、成本、组合摘要、内联 SVG 与原始身份 JSON；专用线程通过 `QSaveFile` 原子保存，失败不留半文件。此操作不联网、不重跑、不使用当前编辑参数，也不是自动发布。范围外仍包括滚动/留出样本外验证、多重检验校正、PDF/CSV/批量报告、外部因子数据集、市值中性化、实际可交易行业中性/分层组合、市场冲击/容量、协方差矩阵、多因子优化器和 LLM 候选生成。

12R 将上段的样本外与多重检验缺口替代为已实现状态：固定 20/10/10 的扩展训练/完整不重叠测试窗，样本外 HAC 只消费测试帧，方法和摘要进入 `factor_research_v6`；当前显式选择且受控可比的归档集合按样本外 IC p 值计算 Holm–Bonferroni 与 Benjamini–Hochberg，候选集 SHA 不写回单项归档。尚未实现自动参数搜索、全历史归档扫描、LLM 候选生成、市值中性化、多因子优化或生产执行。

12S 将候选因子登记与事后结果选择分离：候选假设、受控来源和因子定义快照先形成不可变版本并冻结；只有冻结后严格完成的 v6 样本外归档可标记为前瞻预注册验证，旧结果只能作为明确的回溯参考。schema v15 保存候选版本与关联审计，QML 只提供用户显式登记、冻结和关联，不自动扫描历史、不自动运行实验。LLM 候选生成、授权外部因子导入、自动研究队列和因子有效性判断仍未实现。

12T 接入用户授权外部因子 CSV 的异步两步导入。schema v16 保存不可变数据集、观测和冻结候选绑定；时间显式归一化为 UTC，同值重复幂等、冲突重复拒绝，确认导入必须匹配预览 SHA-256。12U 已在此基础上实现显式异步研究：只使用观测时刻之前已经完成的本地 Tick 派生 Bar，复用 IC/Rank IC、HAC、三段稳定性、五分层/成本和扩展窗 OOS，并以 schema v17 保存候选、授权数据、完整收益数据身份和结果。12V-A 增加全部标的本地覆盖异步预检，只有预检身份与运行参数完全一致才允许研究。真实授权文件及独立时期结论仍未验收；fixture 结果不得解释为因子有效。

2026-08-28 增加纯计算长稳证据：`FactorResearchAnalyzer` 与策略/指标运行时在同一 Release 进程连续运行 15 分钟，每轮处理 60 帧 × 100 标的，累计 1,010,892,000 个标的-帧配对；168,482 轮均成功且校验和一致，因子段 p95 为 1.683 ms。输入为确定性受控帧，只验证实现稳定性和性能上界；没有真实授权外部因子、没有 LLM 候选生成，也不构成因子有效性结论。

## 验收

同一数据版本、因子版本、股票池和参数必须得到可复现结果。任何 LLM 产物都标注为“候选研究”，需要人确认；回测不构成投资建议。
