# A 股大模型辅助与量化因子回测

## 目标

建立可复现的 A 股因子研究能力，并将大模型限制为研究协作者：解释数据、生成候选因子/策略 DSL 草案、总结回测结果；不能直接下单或修改历史结果。

## 因子研究底座

- 因子注册表：ID、定义、参数、频率、适用股票池、依赖字段、缺失值与中性化规则。
- 数据版本：行情、复权、停牌、上市天数、行业分类和股票池均需有时间版本。
- 计算：横截面标准化、去极值、行业/市值中性化、分位数组合和换手率。
- 评估：IC/Rank IC、ICIR、分层收益、年化收益、最大回撤、换手、交易成本和容量提示。

## 大模型边界

大模型通过工具调用获得只读、脱敏、带数据版本的研究摘要。输出必须是结构化候选：因子定义、假设、数据依赖、风险和 DSL 草案。系统对候选进行语法、未来函数、数据可用性和风险校验后，才允许进入回测队列。模型不得访问凭据、执行本机命令、绕过审批或发出交易指令。

## 交付阶段

1. 因子/数据版本/结果存储模型。
2. 单因子 IC 与分层回测。
3. 多因子组合、交易成本和走样检查。
4. 大模型研究助手与候选审查流程。
5. 研究报告：输入、版本、参数、图表和结论可追溯。

## 验收

同一数据版本、因子版本、股票池和参数必须得到可复现结果。任何 LLM 产物都标注为“候选研究”，需要人确认；回测不构成投资建议。
