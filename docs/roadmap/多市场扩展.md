# 美股、外汇与加密货币扩展

## 前提

仅当 A 股阶段的品种目录、策略注册表、回测规则注入、组合模型和数据版本稳定后启动。新市场不得在核心引擎中添加 `if (market == ...)` 分支；应实现 Provider、`MarketRules`、账户币种与数据目录适配器。

## 美股

接入交易所/时区、美元结算、盘前盘后标识、拆分与分红、可卖空和分数股配置。复用单品种、策略、组合和因子页面。

## 外汇

接入货币对、24/5 日历、点值、双向仓位、杠杆、隔夜利息和汇率换算。组合账户必须以基准货币汇总风险与收益。

## 加密货币

接入交易所、现货/合约资产类别、24/7 日历、最小下单量、手续费层级、资金费率与交易所状态。API 密钥只存用户安全存储，研究与模拟模式默认不需要密钥。

## 验收

每个市场独立完成符号映射、交易日历、费用/成交规则、历史数据质量、固定回测夹具及风险限制测试。多市场组合必须显示币种换算时间、汇率来源和不可交易时段。
