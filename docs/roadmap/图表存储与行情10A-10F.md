# 图表、存储与行情路线图（10A–10F）

## 目标与原则

本路线把 K 线交互、数据库迁移、NAS 数据中心和远端行情 Provider 拆成可独立验收的阶段。SQLite 继续作为单机事务状态和热缓存，不直接在 SMB/NFS 共享文件上运行；NAS 保存原始数据并通过受控服务接口提供 catalog、分块读取和变更通知。QML 仍只通过 `TradingController` 访问业务。

## 前置阶段 9C：盘中 Tick 增量追加（已完成）

- 仅接收带稳定 source/sequence、合法交易日和真实成交方向的原始成交；TDX 轮询快照不得冒充逐笔。
- 同批追加使用 SQLite 事务和幂等唯一键，重复事件不重复计数。
- 只使受影响代码、交易日的派生缓存失效，并仅重建已使用周期；UI 更新携带 requestId，旧结果不能覆盖新结果。
- 提供批次写入数、重复数、受影响日期、刷新周期和错误状态；覆盖乱序、重复、跨日、失败回滚和持续刷新测试。

## 10A：TradingView 风格 K 线交互（首个可用基线已完成）

- 滚轮以指针为中心缩放，拖拽平移，价格轴拖拽缩放，双击恢复自动范围。
- 十字线、时间/价格标签、悬停 OHLCV、单击锁定、Esc 取消；右键提供复位和复制数据。
- 视口到达左边界时异步加载更早分页；加载只扩充模型，不改变当前指针锚点。
- 变换和命中逻辑进入 C++ 可测试层，Scene Graph 只重建可见几何；5000 根连续交互作为容量基线。

当前已交付指针锚定滚轮缩放、拖拽平移、可见几何、十字线/标签、锁定与键盘/菜单复位。价格轴独立拖拽、到达左边界后的异步分页锚点保持、复制当前 Bar 仍为 10A 后续项；阶段 10B 可并行建立其依赖的稳定存储身份。

## 10B：数据库版本迁移（已完成）

- 建立全库 Schema 版本和顺序 Migration 注册表，替换零散的建表/加列判断。
- 升级前生成一致性备份，逐版本事务执行，运行 `integrity_check` 和业务表校验；失败恢复旧库。
- 增加 database UUID、迁移历史、应用版本和数据身份，不把凭据写入数据库。

已交付全库 v1、稳定 database UUID、迁移历史、一致性备份、单事务升级、完整性/外键/必需表校验和失败回滚。备份保留期与人工清理入口留在 10C 的存储管理范围内。

## 10C：存储位置管理（后端已完成）

- 新增 `StorageProfile` 与生命周期协调器：停写、排空队列、关闭所有线程连接、备份复制、校验、切换和重新打开。
- 支持任意本地绝对路径安全搬迁；配置写入 `QSettings`，凭据交给系统凭据存储。
- SQLite 文件不直接打开网络共享路径；界面明确区分“本地数据库位置”和“局域网数据端点”。

后端已交付 QSettings 路径配置、活动任务保护、后台连接排空/重连、异步验证复制、UUID/完整性校验、目标覆盖拒绝和失败回到源库。源文件不自动删除。设置页路径浏览与备份清理界面尚未启用，但不影响 10D 数据节点协议实施。

## 10D：NAS 数据节点（v1 首版已完成）

- NAS 端以代码/交易日分区保存原始 Tick，优先采用 Parquet/Zstd，兼容现有 CSV。
- 数据节点提供 HTTPS catalog、范围/分块下载、SHA-256、断点续传和 WebSocket 数据新增通知。
- PPTrader 按需拉取到本地事实表与缓存；断网保留本地数据，重连按 manifest 增量同步。
- 地址必须由用户配置并限制为允许的协议；不扫描整库，不保存明文密码。

已交付标准库只读节点、health、受控日期范围 catalog、CSV 单日下载、Range/ETag/SHA-256、本地校验缓存、异步取消/requestId 门控，以及 QML 显式查询和同步入口。校验通过后复用 TickData 事务导入，不另建事实协议；失败保留既有本地数据。节点已在真实虚拟机上安装为 systemd 用户服务，只监听远端回环地址，并通过 SSH 本地端口转发完成目录和文件摘要验证；仓库只保留通用 unit 模板，实际路径和端口留在目标机环境文件。详细契约见 `docs/nas-data-node-protocol.md`。Parquet/Zstd、完整断点续传状态机、WebSocket 新增通知、Token 轮换界面和 NAS 原生 HTTPS 仍待后续增量完成。

## 10E：远端历史日 K（已完成）

- 扩展 Provider 能力声明与路由：市场、品种、周期、历史起点、复权、限频和授权状态。
- 工程主选候选为 Tushare Pro 日线，BaoStock 与 mootdx 作为免费/兼容回退；先实测沪深京、上市/退市、停牌、复权和长周期一致性。
- 下载结果逐根校验并保存 source、adjustment、downloadedAt 和 dataVersion；Provider 失败不破坏已有缓存。

已交付能力声明、单飞 requestId 路由、45 秒候选超时、Tushare/BaoStock/mootdx 优先级回退、三种复权显式选择和 SQLite v2 数据身份。真实环境中 BaoStock 当前登录不可用，mootdx 回退成功，并通过应用完成 300750 的 500 根日线入库及无网络缓存复用。Tushare 只有环境 Token 存在时才启用。北交所、退市/长期停牌样本和跨源复权一致性基准留待独立质量阶段；详见 `docs/historical-provider-routing.md`。

## 10F：稳定实时行情与主备切换（TDX + 腾讯分钟级基线已完成）

- 当前 mootdx/公共 TDX 保留为免费降级源，不作为唯一生产源。
- 当前产品最低实时粒度固定为 1 分钟，不要求逐笔。若公共源长稳结果不足，再选择 QMT/miniQMT、Wind/iFinD 或券商专业行情作为付费候选。
- Provider Router 统一 Qt 事件，不把 WebSocket、回调或轮询细节泄露到业务层；增加心跳、断线重连、限流、缺口补拉、熔断和质量评分。
- 以 5000+ 标的持续运行、完整率、端到端延迟、断线恢复和主备切换作为最终验收。

已交付 Qt 单活 Router、TDX 固定主备、腾讯 HTTPS 分钟级异构备用、自动发现候选、能力声明、候选级 watchdog、质量评分、熔断恢复及旧源事件门控。TDX 故障注入完成 5156/5207、99.0%；腾讯单源应用验收完成 5207/5207、100%。主页当前品种已接入只驻留内存的腾讯 1 分钟 OHLCV，真实 600519 得到 241 根最近交易日 K 线；历史 Tick 回测链路保持独立。至少 4 小时长稳验收仍待完成，详见 `docs/realtime-provider-routing.md`。

`9C → 10A → 10B → 10C → 10D → 10E → 10F`。每阶段必须更新开发进度和项目 Wiki，并通过串行 Debug 构建、CTest、QML lint；视觉阶段继续在副屏复核。
