# A 股任意组合横截面研究

## 目标

用户可选择任意一组 A 股，在任意可用时刻查看横截面价格、涨跌、成交、板块分布与因子值，并能从组内进入单品种研究与回测。

## 组合来源

- 自选股列表；
- 交易所、板块与行业筛选；
- 指数成分股（需有版本化成分数据后启用）；
- 用户保存的静态组合；
- 研究条件生成的动态组合。

组合是 `UniverseDefinition`，保存规则、成员快照、创建时间和数据版本。动态组合必须记录实际入选成员，保证历史回看可重现。

## 功能阶段

1. 组合选择器与成员模型，支持搜索、保存、删除和成员数量校验。
2. 时刻快照查询：使用“请求时刻之前最近完成批次”的既有语义，明确完整率、陈旧度和数据源健康。
3. 横截面图与表：价格、涨跌幅、成交额、排名、板块过滤和 Top N 使用同一批次、同一过滤版本。
4. 研究联动：点击成员进入个股工作台；将当前组合与时间范围传给因子研究。

## 验收

- 5000+ 全市场与任意子集均使用批量模型/Scene Graph，不创建逐股票 QML Item。
- 成员变化、筛选、时刻变更不得混用不同批次。
- 空组合、缺失成员、低完整率和过期快照都有可见状态。
- 首期不宣称实时指数成分、行业分类或北交所覆盖，除非数据源已验证。

## 阶段 12G–12Q 状态（2026-08-23）

固定组合后端已具备不可变行业数据集、按日期解析快照和行业目标权重上限。12H 已实现本地 CSV 流式校验、异步预览/确认、双哈希、同版本修订链和数据管理页面入口。12I 已让横截面策略按首个对齐帧日期消费同一不可变快照：完整覆盖所有 universe 标的后才运行，超限行业同比例裁剪目标且剩余比例留现金，实际价格漂移只观测不强平；快照与风险摘要随结果归档。12J 为单个策略内 `crossIndicators` 别名增加总体 Z-Score 绝对暴露上限；12K 登记定义/预处理版本并计算下一对齐帧 IC/Rank IC；12L 保存 IC 时间序列、非年化 ICIR 与固定五分层收益及方法身份；12M 以相邻有效帧等权成员计算单边换手，并按用户输入 bps 报告毛/净分层收益和 Q5−Q1 双腿成本；12N 在成对剔除和全市场去极值后对因子做行业内去均值，复用同一不可变行业快照并以 v4 身份归档；12O 只读加载最多 4 个 SQLite 因子研究归档，以逐腿数据、对齐帧和完整研究口径判定“受控可比”或“描述性对照”；12P 对至少 20 个有效帧计算 Newey–West/Bartlett 95% 区间与双侧 p 值，并以三个连续样本内区段描述时间稳定性，方法身份随 v5 归档且进入比较基准；12Q 从明确选择的不可变归档异步原子导出自包含 Markdown 与内联 SVG，绝不读取当前编辑参数或重跑。真实授权来源文件、行业筛选 universe、外部因子库、市值中性化、可交易行业中性/分层组合、多因子优化、滚动样本外验证与多重检验校正仍未实现，不能因测试 fixture 或接口存在而宣称策略有效。

## 阶段 12R 状态（2026-08-23）

上段末尾“滚动样本外验证与多重检验校正仍未实现”已被本阶段替代。横截面因子研究现按 20 帧初始训练、10 帧测试、10 帧步长形成扩展且不重叠的完整测试窗，样本外 HAC 只使用测试帧；`factor_research_v6` 保存窗口、方法和结果身份。最多 4 项归档比较会对当前显式选择、受控可比且具备样本外 IC p 值的候选集计算 Holm/BH，描述性对照排除。该能力尚未经过真实授权因子/行业数据和独立市场时期验收，不是生产因子风险平台。
