# 自定义指标与自定义策略流程审计（2026-09-07）

## 结论

后续状态：本报告保留最初走查事实。指标已扩至 18 类，随后用户授权足宽原生窗口完成有效 BIAS＋WMA 规则保存、重启重载与非零成交本地回测归档；新增验证记录未落库（FLOW-08）和 Bar 回放字段错配（FLOW-09），并记录首次退出残留。详见 [后续补充验收](custom-strategy-signal-lifecycle-2026-09-07.md)。这仍不代表完整流程或通用自定义指标生成器通过。

**目前只能认为具备“内置指标参数化组合 → 单标的、单周期、Bar 驱动的本地回测策略”的基础链路，不能验收为完整的自定义指标／策略方案生成器。**

本轮使用 Computer Use 实际走查八步页面、检查生成与执行源码，并运行既有离线测试。真实应用已到第 8 步、显示校验编译通过，但保存版本被操作安全检查拦下；未绕过，也未执行后续真实 Controller 回测。不能用现有 Stub 控制器测试代替这条端到端验收。

用户口径保持：多个指标共同构成一个策略；每个策略运行实例拥有独立资金、持仓和盈亏。当前单次独立回测可重置独立账户；多策略同时模拟执行还不是按策略实例分账。此审计不证明策略盈利、实盘交易或日频选股与分时入场已协同完成。

## 已确认的问题与修复顺序

以下 FLOW 编号只属于本报告，不覆盖既有 STRAT-R01～R07 或 APP-001 的编号。

### FLOW-01 / P1：非法仓位与风控配置静默改变策略含义

证据：`qml/components/CustomStrategyWizard.qml:230` 的 `buildJson()`；步骤 5 的输入框在同文件 `2492` 附近。

纯函数复现执行仓库原始 QML `buildJson` 和原始 `CustomStrategyWizardContract.js`，结果见 `generation-repro.json`：

| 用户输入 | 实际生成 |
|---|---|
| `positionPercent = "abc"` | `position.percent = 1`，即 100% |
| `positionAmount = "abc"` | `position.amount = 50000` |
| `maxPositionPercent = "101"` | `risk` 中完全不再有最大仓位限制 |
| `stopLossPercent = "abc"` | `risk` 中完全不再有止损限制 |

这份复现证明的是转换行为，不是提交非法参数后的完整回测；未通过 UI 输入非法值。校验应在转换之前逐字段拒绝非法数值，0／空值只有在明确允许关闭某项风控时才接受。不能悄悄把非法值换成更激进仓位或取消风控。

### FLOW-02 / P2：步骤绿勾不代表实际验证成功

可见应用中没有保存版本、没有运行回测，点击第 7 步的“下一步”后，第 7 步仍显示绿勾。源码 `CustomStrategyWizard.qml:820` 的 `completedStep` 仅为 `stepNumber < activeStep`。

修复应区分“已浏览”“配置有效”“已保存”“该版本该数据已回测”“允许上线”。建议在第 7 步提供保存研究版本入口；第 8 步在能力尚未上线前称“保存研究方案”，不得把走过页面当作验收结果。

### FLOW-03 / P2：向导布局不适应现有 Windows 半屏排列

实际半屏下中央表单近乎不可用。`CustomStrategyWizard.qml:779` 左栏固定宽 300，右预览与中间内容同时占位；工作台嵌入后的尺寸不能满足原设计。修复应使窄窗口折叠／切换预览、表单可滚动，并保证底部按钮始终位于可操作范围。回归至少包括本次 1280 宽、最大化与 Windows 吸附布局。

### FLOW-04 / P2：无草稿默认条件无法触发

源码确认，尚未另开清洁设置 UI 复现：`CustomStrategyWizard.qml:666` 创建两条 SMA，只改别名为 fast/slow；`CustomStrategyValidator.cpp:783` 的 SMA 默认周期均为 14。默认条件要求 fast 上穿 slow，两条完全相同的序列不可能发生该交叉。

应提供明确不同周期的示例，并加入带已知信号的数据测试；“零交易”必须与不可触发配置区分，而不是仅给出编译通过。

### FLOW-05 / P1：多股入出场条件已配置、编译，却未参与目标仓位计算

源码核查，需补受控差分回归：`CrossSectionalBacktestContract.js:179` 生成 entry/exit；Compiler 编译；`CrossSectionalCustomStrategy.cpp:134` 只按横截面排名和 Top-N 返回 targetWeights，`CrossSectionalBacktestEngine.cpp:249` 直接使用权重，未求值这些 entry/exit。

最小验收：相同股票池、排名与数据，只将入场条件从恒真改恒假；恒假必须阻止入场。若暂不支持，应拒绝此配置或移除误导输入，不能静默忽略。

### FLOW-06 / P1：普通 JSON 工作台没有 DSL v3 运行能力分流

源码核查，需补真实入口回归：`CustomStrategyWorkbench.qml:28` 的 canRun 依赖编译和数据可用性；`TradingController.cpp:3282` 把编译成功当 executable；最终普通运行路径 `TradingController.cpp:8940` 使用 `CustomBacktestStrategy`。后者 `evaluateOperand():207` 不执行 Cross 操作数。

需要在分析／保存运行可用性／运行器入口统一拒绝错误能力或转交横截面引擎，防止“编译成功但跨股条件没有信号”的假完成。

### FLOW-07 / P2：异步预览、保存与编辑状态没有完全绑定

- 向导预览完成只比 requestId，然后接受结果并清除 previewDirty（`CustomStrategyWizard.qml:2987`）；没有以策略内容哈希＋数据版本＋样本窗确认是当前研究上下文。
- Workbench 异步保存后无条件 loadDefinition（`CustomStrategyWorkbench.qml:303`），会覆盖保存请求发出之后继续编辑的内容；需延迟回调场景验证。
- 预览服务是信号预览，不是资金回测；读取缓存的路径与正式数据集身份核验路径不同。预览通过不等于策略含资金／费用的回测通过。

以上先列为源码确认的缺口，不能冒充已在真实应用中复现竞态。应补慢请求、修改草稿、切数据、旧结果迟到、保存中继续编辑的回归。

## 尚未实现的能力，不应包装成 Bug 已修复

1. **独立自定义指标**：当前只能参数化 SMA、EMA、RSI、MACD、BOLLINGER、ATR、VOLUME_SMA、ROC、VWAP、PP_FLOW。没有自定义公式定义、独立 ID／版本、保存目录、跨策略引用和依赖校验闭环。图表 MA 参数属于图表偏好，不自动成为策略指标；横截面因子研究和授权 CSV 导入也不是通用指标编辑器。
2. **指标组合是策略的一部分**：`series` 内嵌在不可变策略 JSON 中，别名只在此策略内有效。向导固定 DSL v2、`parameters: []`、`backtest_only`；生成的是具体参数方案，不自动生成可搜索参数槽／穷举空间。
3. **逐笔自定义策略**：该向导对应 `CustomBacktestStrategy::onCandle`，`onTick` 为空。历史 Tick 派生成 1m K 线后回测，不等于原始逐笔策略。
4. **多周期协同**：日频选股、分钟／Tick 进场尚不能通过这一份向导方案完成多时钟调度。DSL v3 多股表单是另一条路径，不能把它视为 v2 向导切个开关。
5. **每策略独立账户**：一次 BacktestEngine 运行会重置独立现金与持仓；`StrategyExecutionCoordinator.cpp:212` 的模拟执行仍读取公共 orderPort 账户、按 symbol 找持仓。下一阶段必须用 strategyRunId/accountId 隔离多个策略实例，而不是每个指标一个账户。
6. **完整研究方案与上线**：还需固定本次运行的数据身份、样本窗、周期、参数、初始资金、费用／撮合模型、风控、结果与版本关联；然后才是独立账户、模拟运行审批与监控。当前第 6 步和右侧固定摘要不能替代这些配置。

## 下一步最小完整验收

得到隔离数据库保存与离线回测确认后，使用明确、非空信号的正常参数样例：

1. 由向导创建两项以上指标与入／出场规则，导出并核对每个字段，不静默修正非法值。
2. 保存 v1，关闭并重新打开；核对内容哈希与版本不可变，另存 v2 不影响 v1。
3. 真实 Controller 选择版本、本地数据身份、样本窗与初始资金，调用真实数据集服务和 BacktestEngine。
4. 对照手算小样本检查指标、信号、成交、费用、T+1、账户与持仓；不得以“完成且零报错”替代计算正确。
5. 修改一个周期／阈值，验证新版本与结果关联，并确认旧预览、旧回测不能冒充当前方案；同一版本同一输入结果确定。
6. 补齐多股条件差分、v3 入口能力门禁以及同股票双策略资金隔离测试后，再扩大到 A 股选股＋分时入场研究。

本轮结论是**有基础实现，但流程与能力尚不完整；保存后真实应用回测仍待确认与执行**，不是验收通过。
