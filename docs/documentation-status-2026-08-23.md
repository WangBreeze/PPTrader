## 事实与边界

- `FactorResearchAnalyzer` 只修改研究因子值，不改变策略目标权重、成交或下一帧收益。
- 小于配置阈值的行业不会补零、合并到“其他”或保留原因子值；其样本从该帧剔除并计数。
- `CrossSectionalBacktestService` 只在行业权重约束或行业去均值任一启用时解析行业快照；两者同时启用不会加载第二套行业解释。
- SQLite 当前 schema 为 v17；12N–12R 只扩展既有 JSON 身份或只读模型，12S 新增候选版本和验证关联表，12T 新增授权外部因子数据集、观测与候选绑定，12U 新增独立研究归档。旧阶段“schema v14/v15/v16”表述保留为当时事实。
- 12T 串行 Debug 全量构建成功，CTest 38/38（52.19 秒）和 `all_qmllint` 通过；副屏 `originX=-2561`、2560×1393 实际启动并进入多股页。视觉检查发现并修复右侧固定列裁剪，最终授权数据卡片可通过独立滚动区完整显示，控件与真实空态进入可访问性树。最终列宽修正后再次完成 `PPTrader` 目标构建、QML lint 与启动复核。未选择文件、未写入授权数据、未运行研究、未联网或访问 NAS。
- QML 只经 `TradingController` 配置开关、最小组样本和行业数据集，并显示真实应用帧/样本/剔除统计或空态。
- 12O 的受控比较基准不包含因子 ID/版本，因为不同因子是比较对象；但包含周期、样本、股票池、逐腿数据、对齐帧、日历、预处理、收益/分层/成本与中性化身份。
- 12P 的推断方法身份也进入比较基准；旧 v1–v4 结果不会在加载时补算成 v5。
- HAC p 值只是在既定单因子样本上的正态近似结果，不校正因子挖掘、多重比较或选择偏差。
- 12Q 报告构建器只接收不可变 `PortfolioArchiveRecord`；Controller 要求当前结果已有归档 ID，异步服务以 requestId 门控并用 `QSaveFile` 提交。schema 保持 v14。
- 12R 的“训练窗”只表示时间隔离；当前因子定义固定，不进行拟合、调参或自动择优。
- 单项归档保存自身样本外结果；Holm/BH 依赖当前比较候选集，只保存在内存模型中，候选集变化即重新计算，不污染归档。
- 样本外与多重校正降低部分统计误读风险，但不消除数据窥探、选择偏差或市场制度变化风险。
- Markdown 的内联 SVG 是否直接显示取决于阅读器；身份 JSON 会先做 HTML 转义，用户可见表格字段也会做 Markdown 转义。
