# 原始 Tick 嵌套 walk-forward

## 结论

H3B.9C 已完成单标的原始 Tick 嵌套 walk-forward。用户可显式选择 1～20 折；1 折保持 H3B.9B 的单次最终留出，2～20 折才进入扩展训练窗。每一折都重新在该折训练段扫描完整候选集，确定性选出一组参数后，只在严格更晚且不重叠的验证段评估。运行始终只读本地 SQLite，不访问 Provider 或 NAS，结果固定为 `researchOnly`。

## 时间隔离与结果

若共有 `D` 个实际观测交易日、外层折数为 `F`、每折验证日为 `V`，则至少需要 `2 + F × V` 日。初始训练窗为前 `D - F × V` 日，后续折把上一折验证段加入训练范围；每折训练与验证均使用全新回测引擎状态。

结果保存每折训练/验证日期、Tick 数、两侧 SHA-256、候选排名、选中参数及验证摘要，并提供验证收益均值、中位数、最差/最好值、正/非正收益折数和选参分布。跨折指标仅是描述性统计，不包含 p 值、多重检验、收益保证或模拟/实盘准入判断。

## 身份、恢复与界面

嵌套身份包含策略、费用/整手、候选集合、数据集版本、折数、每折验证日及所有折的数据身份和选中参数。v23 的 `raw_tick_parameter_sensitivity_results` 已使用完整 JSON 保存不可变研究记录，因此本阶段无需提升 schema；旧单折归档继续按原 v1 身份恢复。缺折、折号错误、训练/验证交叉或顶层摘要不等于末折时拒绝归档。

`TradingController` 保留原 7 参数单折入口，并新增带折数的重载。QML 参数研究区提供“外层折数”，显示每折边界、参数和验证结果；没有把多条重置后的权益路径拼成伪连续曲线。

## 真实受控验收

使用上一阶段已同步的跨月隔离 SQLite，对一个真实 A 股数据集、`tick_momentum`、2×2 候选、3 折×5 个验证日重复运行两次。2/2 成功，结果 ID、完整身份和逐折选参均一致；装载 p50/p95 为 699.5/703.6 ms，扫描为 30,207/30,254.7 ms，总耗时为 30,915/30,957.3 ms。

三折分别为：

- 训练至 2026-08-07，验证 08-10～08-14：388,993 / 22,007 Tick，验证收益 -1.60%；
- 训练至 2026-08-14，验证 08-17～08-21：411,000 / 22,780 Tick，验证收益 +0.62%；
- 训练至 2026-08-21，验证 08-24～08-28：433,780 / 22,555 Tick，验证收益 +1.46%。

验证收益均值为 +0.16%，中位数 +0.62%，2/3 折为正；三折选择同一参数。该单标的、小候选集结果只能证明生产链路、隔离和重复性。跨策略、跨标的、跨年度统计推断仍未完成。

较大 3 标的×3 策略×2 次队列曾在 512 秒时因缺少逐项进度且队列过长而人工中止，未形成验收报告；探针随后改为任一请求超时即停止剩余队列，并提供 2×2 受控候选档。机器可读证据为 `artifacts/raw-tick-nested-walk-forward-2026-08-29/report-release.json`。
