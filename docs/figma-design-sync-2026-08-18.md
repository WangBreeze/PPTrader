## 已确认的产品设计

### 1. 顶层信息架构

顶层工作区固定为五项：**主页、市场快照、指标与策略、回测任务、执行中心**。多窗口是主页内的工作能力，不占用顶层导航项。

在 1600×1000 基准画板上，公共导航从 x=250 开始，按钮高度 36，间距 8；按钮宽度依次为 76、90、104、82、82。当前页使用选中态，其余项保留默认、悬停、键盘焦点和禁用状态。

### 2. 主页双工作区

主页保持左侧品种工作区与右侧图表工作区：

- 左上为实时品种列表与搜索，右上为对应实时图表。
- 左下为回测品种列表与搜索，右下为对应历史/回测图表。
- 实时品种与回测品种独立选择；切换一侧不得覆盖另一侧的品种、周期、视口或任务状态。
- 任意已支持的 A 股均可从搜索或列表切换。切换期间旧图保留并显示加载层，成功后原位更新；失败时保留原选择并给出可重试错误。
- 两张图都提供周期控制、指标显隐、十字光标和入场/出场标记；没有对应数据时显示明确空状态，不绘制示例行情。

### 3. 回测入口与状态连续性

- 主页回测区提供“运行回测/进入回测任务”入口。
- 回测品种、周期和策略已就绪时可发起任务；缺项时按钮禁用，并在控件附近说明缺失条件。
- 运行后可切换到“回测任务”查看进度、结果、成交明细和错误。
- 在五个顶层页面间切换时，运行中、成功、失败、取消和结果状态都应保持；具体状态持久化方式由开发实现决定，设计不限定页面实例技术方案。
- 主页下方图表只展示与当前回测品种和任务对应的结果，禁止把其他品种的旧结果误显示为当前结果。

### 4. 多窗口

- 实时图表和回测图表均保留独立“打开多窗口”入口。
- 子窗口继承打开时的品种、周期和指标配置，之后允许独立切换。
- 若运行环境尚未提供窗口能力，入口使用禁用态并显示原因；不设计无反馈的占位点击。

### 5. 数据与示例边界

- Figma 中的 AAPL、BTC-USDT、NASDAQ、模拟券商等只作为视觉样例，不代表当前产品已支持相应市场或数据源。
- 当前交接语义以 A 股股票池、行情快照/实时链路与本地历史 Tick/K 线为准。
- 所有价格、收益、成交和运行状态都必须由真实模型提供；设计稿内的数字不作为默认数据写入产品。
- 数据来源、缓存方式和传输方式不在普通图表界面突出展示；只在用户需要判断可用性时显示“实时、本地历史、陈旧、错误”等业务状态。

## 开发交接（待实施，不是本轮代码改动）

1. 使用统一 64px 公共顶栏承载五项导航，主页不再保留第二套旧顶栏。
2. 主页实时与回测选择器维持独立状态，图表请求和加载/错误状态也分别管理。
3. 品种切换采用“保留旧图 + 加载层 + 原位更新”的连续交互，避免整页闪白或重建页面造成状态丢失。
4. 回测入口与顶层“回测任务”共享同一任务语义，返回主页后保持当前品种、周期和结果。
5. 多窗口能力必须有真实窗口接口后再启用；未接线前使用带原因的禁用态。
6. 页面只展示真实数据和真实状态，不使用 Figma 示例数字填充运行界面。

## 设计验收清单

- [ ] 主页、市场快照、指标与策略、回测任务、执行中心五项导航顺序和选中态一致。
- [ ] 主页只存在一套公共顶栏；1600、1279、1120 宽度下导航不与右侧状态区重叠。
- [ ] 实时和回测品种可独立切换，切换任一侧不会改变另一侧状态。
- [ ] 切换品种时有加载、成功、空数据和错误反馈，旧图不会被错误数据瞬间替换。
- [ ] 回测运行中切页再返回，任务与结果上下文保持。
- [ ] 图表的周期、指标显隐、入场/出场标记与数据状态可辨认。
- [ ] 跨市场样例不会被误实现为已支持能力。
- [ ] 多窗口未接线时有明确禁用原因，接线后继承正确的品种与图表配置。
- [ ] 键盘焦点可见，状态不只依赖颜色表达，禁用控件可获得原因说明。
