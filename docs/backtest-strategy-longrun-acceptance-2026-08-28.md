# 回测、策略与指标长稳验收（2026-08-28）

## 结论

本轮两项 15 分钟 Release 单进程长稳均通过既定预算，随后补充的 500 任务调度长稳也通过。三项均为离线验证，未访问 NAS、历史 Provider 或实时行情。100 档回测使用既有授权样本形成的本地 SQLite 副本并以只读方式打开；500 任务档复用一个真实 Tick 派生数据形状生成 500 个容量身份，因此只证明调度和引擎稳定性；策略与指标计算使用确定性受控序列，目的是隔离运行时稳定性，不用于评价策略收益或因子有效性。

## 边界与后续

- 100 个回测数据集均来自真实本地 Tick 派生缓存，但每个仅取 100 根；这是长稳与并发执行证据，不是多年历史回测或 500/5207 标的容量声明。
- “策略生成”指当前声明式 JSON DSL 的受控生成、校验和编译，不包含 LLM 生成、自由代码或插件动态生成。
- 因子输入为确定性受控帧，只证明计算链稳定；真实授权外部因子的独立时间段验收仍待用户提供数据。
- 本轮未覆盖 QML 连续人工编辑、SQLite 结果长期归档增长、NAS 故障恢复、Provider 波动或多日原始 Tick 装载。500 个独立真实历史数据集和 5207 档端到端装载仍延期；500 任务调度通过不能替代它们。
