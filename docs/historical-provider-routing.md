# 远端历史日 K Provider 路由

## 访问边界

远端历史数据只由“指标与策略 → 本地历史数据 → 下载并保存本地数据”显式触发。打开页面、搜索股票、刷新本地目录、选择回测品种和运行严格本地回测都不会联网。路由当前只声明上交所、深交所 A 股；北交所留待独立验证。

## 候选源与优先级

1. `tushare_pro`：主选候选，支持日线、不复权/前复权/后复权。只有运行环境提供 `PPTRADER_TUSHARE_TOKEN` 才加入路由；Token 不写数据库、日志或文档。
2. `baostock`：免费日线回退，支持三种复权方式，无凭据。当前开发机真实请求在登录阶段被上游套接字拒绝，路由会记录失败并继续尝试下一源。
3. `mootdx`：兼容回退，支持日线和分钟线，但仅不复权。2026-08-09 真实请求成功返回日线；它不是生产级 SLA 数据源。

Provider 公开市场、venue、周期、历史起点、复权、单次上限、限频、授权与配置状态。路由按优先级选择满足能力的源；45 秒无响应会终止该候选。新 requestId 会淘汰旧路由，迟到响应不能覆盖当前请求。

## 归一化与数据身份

所有来源进入统一 `Candle` 前逐根校验 symbol、周期、时间、有限且为正的 OHLC、高低关系和非负成交量。成交量统一为股：Tushare 和 mootdx 的日线原始“手”乘 100，BaoStock 保留其股数。价格不在客户端自行复权；`qfq/hfq` 只接受 Provider 明确返回的对应口径。

成功数据以单事务写入 `candles` 和 `historical_dataset_versions`。身份包括 `source`、`adjustment`、UTC `downloadedAt`、请求/实际根数、首末时间及由规范化 OHLCV 生成的 `sha256:` `dataVersion`。当前 `candles` 每个 symbol/period/time 只保留一个活动价格口径；切换复权方式会替换重叠 K 线，而不是并存多份。回测归档继续保存当次不可变 dataVersion。

缓存只有在 symbol、周期、复权口径和根数同时满足时才复用；Provider 失败不删除或覆盖已有缓存。运行依赖由仓库 `.venv` 和 `requirements.txt` 管理。
