# 组合资金回测设计（H3C）

最后更新：2026-08-22

## 目标与不变量

H3C 提供**组合资金回测**：一组 A 股共享一个初始资金池，按目标权重定期再平衡，组合级成交约束与风险在引擎内强制。它与 H3A/H3B 的"每标独立资金任务矩阵"严格区分，不得混用描述。

不变量：

- 组合输入只使用 `raw_tick_cache_v1` 数据集（与 H2 身份一致）；所有腿必须同周期。
- 组合资金池唯一：初始资金、现金与持仓市值合计为组合权益，调仓只在该池内买卖。
- 结果可复现：固定定义、数据与参数产生相同权益曲线与成交。
- 成交与风控与单标的引擎一致：A 股整手、手续费、滑点、T+1（当日买入不可当日卖出）。
- 组合引擎独立于单标的 `BacktestEngine`，不改动既有回测/批量链路。

## 估值与调仓语义

- 权重：每腿显式 `targetWeight`；未指定（0）的腿等权均分，权重自动归一化。
- 调仓周期：`rebalanceEveryTradingDays`（默认 1），按**共同交易日**计数（所有腿当日都有数据）；建仓日为第一个共同交易日。
- 调仓时点：共同交易日最后一根 K 线收盘价；买入 `close × (1 + slippage)`，卖出 `close × (1 - slippage)`，手续费 `price × quantity × commissionRate`（与 `BacktestEngine` 公式一致）。
- 先卖后买：超配腿先按可卖数量（T+1 排除当日买入）卖至目标市值，再用可用现金买入低配腿至目标；买入按整手向下取整。
- 停牌/缺日腿：从首个共同交易日起，权益曲线覆盖各腿**已观测交易日并集**。当日有报价的腿更新收盘价；无报价但有持仓的腿沿用最近已知收盘价，并在 `PortfolioPosition.priceStale` 标记。缺腿日只估值、不调仓，也不推进共同交易日调仓计数。
- 日历边界：2024–2026 权威市场日历已注入固定组合；完整覆盖时可为所有腿均缺报价的交易日生成仅估值点。标的停牌必须来自显式事实记录，缺记录保持未知，不从 K 线缺失推断。
- 组合级限制：`maximumLegWeight`（单腿权重上限，超限归一化）、`maximumActiveLegs`（0 为不限制；超过时按权重排序剔除最小腿）。
- 行业目标上限：`maximumIndustryWeight` 为 0 时关闭；开启时必须固定不可变 `industryDatasetId`。行业数据结构始建于 schema v12，v13 增加导入审计元数据。服务按首个共同交易日解析所有腿，缺一条即拒绝。超限行业内各腿同比例裁剪，剩余资金留现金，不重新分配到其他行业。
- 实际行业权重可能因价格漂移在两次调仓之间越过目标上限；结果记录峰值与越限帧，不把目标约束伪称为逐时硬清仓。
- 因子行业去均值：只用于策略内因子研究统计。顺序固定为成对剔除、全市场分位数去极值、行业组内因子减均值；下一对齐帧收益保持原值。小组整组剔除，完整覆盖为硬门禁。若行业目标上限同时启用，两者复用同一 `industryDatasetId`、日期和不可变快照。
- 横截面策略可选择一个自身 `crossIndicators` 别名作为因子暴露约束。每帧使用总体 Z-Score，目标超限时同比例降低全部风险权重并留现金；实际暴露缺值时标记不可测，不前向填充。因子定义和口径以 SHA-256 身份随结果归档。

## 明确不包含（v1）

- 策略信号驱动调仓（仅固定权重）；做空、杠杆、融资；跨日 T+0；VaR、协方差风险矩阵与多因子优化器。
- 真实授权行业/因子来源验收；当前本地 CSV 两步导入、横截面行业目标约束与策略内单因子暴露上限已实现，但没有生产因子数据平台。
- 组合内同日频繁交易（调仓仅在共同交易日收盘执行一次）。
- 组合级 `winRate`（单笔组合成交盈亏无法定义），结果中为 0；`sharpeRatio` 基于组合权益曲线计算。

## 归档与恢复

`portfolio_backtest_results` / `portfolio_equity_points` / `portfolio_trades` 三表单事务保存组合定义、数据集身份、权益曲线（含每期持仓）与调仓成交；行业约束结果必须保存完整行业快照身份，因子约束结果必须保存所选指标定义、定义 SHA-256 与固定计算口径，行业中性化还必须保存 v4 策略、处理顺序及共享快照身份，否则拒绝归档。`priceStale` 随持仓 JSON 向后兼容保存，旧归档缺少字段时默认 `false`。应用启动只恢复摘要目录，用户显式加载后查看历史快照，不联网、不重跑。
