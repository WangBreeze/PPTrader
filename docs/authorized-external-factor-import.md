# 授权外部因子数据导入

阶段 12T 只接收用户显式选择的本地或已挂载盘符 CSV，不扫描目录、不访问网络或 NAS。选择文件本身不会读取；“异步预览”逐行校验但不写库，“确认导入”会重新计算文件 SHA-256，只有与预览一致时才事务写入 SQLite。

## CSV 契约

文件必须是 UTF-8，并带精确表头：

```csv
timestamp,symbol,value
2026-08-20T15:00:00+08:00,600519,1.25
2026-08-20T07:00:00Z,000001,-0.5
```

- `timestamp` 必须是带 `Z` 或时区偏移的 ISO 8601 时间，入库统一转为 UTC。
- `symbol` 当前只接受沪深六位 A 股代码，北交所不在本阶段范围。
- `value` 必须是有限数值；`NaN`、无穷值和空值拒绝。
- 相同 `timestamp+symbol` 且值相同的行幂等去重；值冲突则整批拒绝，并报告行号和原因。
- 因子键、来源版本、授权来源引用、候选因子定义摘要和文件内容摘要共同形成不可变数据身份。

## 存储与治理

schema v16 使用 `external_factor_datasets` 保存数据集身份，`external_factor_observations` 保存观测，`factor_candidate_dataset_bindings` 保存冻结候选与数据集的绑定。数据集和绑定均不支持覆盖或删除；相同内容重复导入/绑定会复用既有身份。只有已冻结候选且其因子定义 SHA-256 与数据集一致时才能绑定。

12T 本身不会自动运行研究，也不会把绑定宣称为有效性证据。后续 12U 已提供用户显式启动的严格本地研究入口：只读取绑定数据集和本地 Tick 派生 K 线，不调用 Provider；结果写入 schema v17 独立归档。详见 `external-factor-research.md`。当前仍未使用真实授权文件验收。
