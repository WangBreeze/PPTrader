# 因子研究使用 HAC 推断与样本内连续分段

PPTrader 的因子研究方法 `factor_research_v5` 对至少 20 个有效帧的 IC / Rank IC 序列，采用 Bartlett 权重的 Newey–West 长期方差估计均值标准误，滞后阶数固定为 `floor(4 × (n / 100)^(2/9))`，并报告 95% 正态近似置信区间与双侧 p 值。少于 20 帧或标准误不可计算时明确标记不可用，不用零值替代。

时间稳定性固定为按有效帧顺序等数量划分三个连续样本内区段，报告各段均值和符号一致性。该结果只描述当前样本的时间漂移，不称为样本外验证。方法、阈值、置信水平、滞后规则和分段规则均进入不可变归档身份；旧版 `factor_research_v1`–`v4` 保持只读兼容。
