# ADR 0007：因子研究采用扩展窗样本外验证与显式多重检验集合

## 决策

`factor_research_v6` 对按时间严格递增的 IC / Rank IC 序列执行扩展窗样本外验证。默认初始训练窗 20 帧、测试窗 10 帧、步长 10 帧；训练窗持续扩展，测试窗固定、不重叠，只接纳完整测试窗，末尾不足 10 帧时丢弃。测试帧必须严格晚于对应训练帧，且不做参数重拟合。

样本外均值和 Newey–West/Bartlett 推断只使用所有测试窗拼接后的序列。拼接测试帧少于 20 或方差不可估计时，区间与 p 值明确不可用。窗口策略、方法版本、推断方法和完整结果进入不可变归档身份；旧 `factor_research_v1`–`v5` 只读兼容，不补算。

Holm–Bonferroni（FWER）与 Benjamini–Hochberg（FDR）只作用于用户当前显式选择、研究基准身份一致、且具有样本外 IC p 值的归档，显著性水平固定为 0.05。描述性对照和不可用结果不进入候选集。候选集 SHA-256 由排序后的结果 ID 与原始 p 值生成；它属于当前比较会话，不写回任何单项归档。

## 边界

这里的“训练窗”只表示时间隔离，不代表自动拟合或选参。样本外显著和校正后显著仍不能证明因果、消除因子挖掘偏差或保证未来收益。真实授权数据和独立研究复核仍是上线门禁。
