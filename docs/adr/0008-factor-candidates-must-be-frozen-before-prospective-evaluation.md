# ADR 0008：候选因子必须先冻结再认定前瞻验证

## 决策

候选因子以不可变版本登记，内容固定包含名称、事前假设、受控来源、来源引用和因子定义快照，并计算 SHA-256。来源当前只允许人工登记或用户授权导入；同一候选内容重复登记复用已有版本，内容变化创建新版本。冻结时间一经写入不可修改，冻结后若需改动假设或定义，必须登记新版本。

验证关联分为两类。`prospective_holdout` 只接受完成时间严格晚于冻结时间、且包含 `factor_research_v6` 扩展窗样本外身份的横截面归档，才标记为预注册证据。`retrospective_reference` 可关联已有因子研究归档，但永久标记为回溯参考，不计入预注册证据。关联保存候选内容摘要、归档因子/方法身份和归档身份摘要，不回写或重新解释原归档。

## 边界

候选目录和验证关联只在用户显式操作时读取或写入本地 SQLite，不自动扫描历史归档、不自动运行回测、不访问 Provider 或 NAS。冻结和时间顺序只能约束事后选择偏差，不能证明因果、策略有效或真实数据质量。LLM 候选生成、外部因子数据导入、自动实验队列和生产执行均不在本阶段范围。
