# ADR 0010：外部因子研究只使用已完成本地 Bar

## 状态

已采纳，2026-08-23。

## 决策

授权外部因子观测在时刻 `t` 只能匹配 `startTime + periodSeconds <= t` 的最近 `raw_tick_cache_v1` 收盘价。下一观测收益使用两个观测时刻各自可见的已完成价；未完成 Bar、网络 Provider 和自动数据补齐不进入执行路径。

每次结果必须保存冻结候选、绑定授权数据集、研究策略以及所有本地收益腿的完整 `BacktestDatasetIdentity`。任一腿缺失、陈旧或周期不一致即拒绝运行。成功结果以 schema v17 单事务归档；历史加载不重算。

## 后果

该口径避免已知的 Bar 内前视，并让外部因子结果可以离线复现。代价是边界时刻可能只能使用更早的完成价，且数据不完整时研究直接失败。真实授权来源和独立时期有效性仍需另行验收。
