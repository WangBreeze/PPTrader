# 因子 IC 使用下一可用对齐帧收益

## Status

Accepted — 2026-08-22

## Context

横截面因子在当前对齐帧收盘后才完整可知；若与同帧收益相关，会产生前视解释。不同标的还可能因缺报价而缺少下一帧价格。

## Decision

IC 固定使用 t 帧因子预测下一可用对齐帧的 close-to-close 收益。缺失或非有限的因子/收益按标的成对剔除；每帧不足最小样本数或方差为零则跳过；跨帧 IC 与 Rank IC 等权平均。该口径随不可变因子版本和回测归档保存。

## Consequences

研究统计不会使用同帧信息，也不会前向填充缺失值；但不等同固定日历持有期、因子收益或可交易组合绩效。未来若增加多周期收益，必须作为新的版本化口径。
