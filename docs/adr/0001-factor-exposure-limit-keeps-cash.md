# 因子暴露超限时同比例降风险并保留现金

## Status

Accepted — 2026-08-22

## Context

横截面策略已经能产出目标权重和策略内因子值，但项目尚无协方差矩阵、通用风险模型或有版本身份的组合优化器。约束层不能暗中改变策略选股排序。

## Decision

首版因子暴露上限采用“所有正目标权重同比例缩小、剩余比例留现金”。现金暴露为零；每帧使用总体 Z-Score。此策略固定为 `proportional_de_risk_to_cash` 并随归档保存。

## Consequences

结果确定、可解释且不会伪称因子中性，但可能保留较多现金，也不会主动寻找更高资金利用率的替代组合。未来正式优化器必须作为新的版本化分配策略，不能改写既有归档解释。
