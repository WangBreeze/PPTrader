# ADR 0009：授权外部因子数据必须显式导入并保持不可变

## 决策

外部因子数据只接受用户显式选择的 `authorized_csv`。预览和确认导入均在专用线程逐行读取；预览不写库，确认时必须重新校验同一文件和元数据的 SHA-256。时间必须带明确时区并统一为 UTC，当前标的范围只包含沪深 A 股，非有限值和冲突重复会拒绝整批数据。

schema v16 将数据集身份、观测和候选绑定分表保存。相同内容幂等复用，内容变化形成新数据集，不覆盖旧观测。候选必须先冻结，且因子定义摘要必须一致，才能建立不可变绑定。浏览目录、选择候选或查看数据集目录不读取 CSV、不联网、不自动运行研究。

## 边界

阶段 12T 的绑定只证明“冻结候选明确引用了哪份授权数据”，不证明数据真实、独立或因子有效。没有用户授权的真实文件时只能使用临时 fixture 验证软件契约。外部观测进入 `factor_research_v6`、独立时期研究与前瞻归档属于后续 12U；LLM 生成、自动实验队列、生产因子服务和交易执行不在本决策范围。
