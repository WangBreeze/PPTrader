# 原始 Tick 参数敏感性跨月 NAS 验收

## 结论

H3B.9B 已完成 2026 年 6–8 月真实 NAS 来源数据的跨月验收。10 个沪深 A 股标的共同步 530/530 个原始逐笔文件，写入隔离 SQLite 的 3,030,617 条 Tick 和 121,067 根 1 分钟派生缓存均成功。生产参数敏感性服务在 Release 下完成 60/60 次请求，30/30 个“标的×策略”身份、选参和结果 ID 重复稳定。

短窗与跨月窗口的胜出参数有 23/30 发生变化。这证明此前 5 日结果只能作为链路与重复性基线，不能代表跨月参数稳定。

## 数据同步

- 节点先通过健康检查和单代码、单日非空预检；预检写入 4,354 条 Tick、240 根 Bar，零失败。
- 范围为 2026-06-10～2026-08-28；每标的实际 49～54 个文件。共同覆盖 47 个交易日，7 月中旬存在真实目录空档，未补零或伪造交易日。
- 源 CSV 合计 184.98 MiB；隔离 SQLite 约 1,012.78 MiB，包含类型化原始事实、索引和 1 分钟缓存，约为源文件的 5.48 倍。
- Debug 同步耗时 28.34 分钟，其中流式解析 17.94 分钟、原始事实事务写入 9.45 分钟、K 线缓存写入 32.92 秒。
- 容量探针新增向后兼容的显式代码和起止日期参数；超过 31 天的查询自动拆分为多个 manifest，仍复用现有下载、SHA-256、流式解析和事务入库链路。单日 `--date` 用法保持不变。

## 超时缺陷与修复

首次 Debug 全量运行的首请求超过固定 120 秒后，探针未等待工作线程确认取消，后续 59 个请求因服务仍为 busy 而立即拒绝。30 秒中段超时最小复现连续两次均得到 3 个级联拒绝。探针现支持显式请求超时，并在超时后等待取消确认；30 秒复测级联数降为 0。正式跨月验收使用 Release 和 900 秒上限，最大单请求 45.215 秒，未触发超时。
