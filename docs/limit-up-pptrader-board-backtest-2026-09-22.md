# PPTrader 原始 Tick 二板／三板接力回测（2026-09-22）

## 纠正：一个资金仓面向股票池

下面的“58/58 逐股回测”只用于核对二板／三板信号和严格数据准入，**不是组合收益或资金验收**。按“一套策略、一个资金仓、股票池中多股分别计算指标”的目标，已新增 PPTrader C++ `BoardPortfolioBacktestEngine`：所有标的的二板／三板信号统一经过 100 万元现金、最多 20 只同时持仓、整手、费用、滑点及 T+1 账簿，不再给每只股票分配独立本金；未完成持仓不强制伪造成交。

读取同一隔离库的 897,158 条原始 Tick，以前序严格准入的 58 个去重事件为允许入场范围、按时间／代码／原始行号稳定排序后的**单仓抽样重放**：覆盖 55 个不同代码，57 个允许范围内的买入信号全部成交、54 笔策略卖出、期末 3 笔仍持有，入场日收盘封板观察事实 13 次；最高同时持有 10 只。58 个事件与 57 笔买入并非漏算：`002585` 在 2026-09-16 再次成为候选时，前一笔 09-15 持仓尚未于 09:35:36 卖出，统一持仓账簿不允许同股重复开仓。另有 4 个准入事件之外的信号被忽略；本样本在 100 万元／20 只限制下没有因现金或持股上限拒买。现金流水由买入支出和卖出净收入重算，差额为 0。

期末现金为 834,288.36 元，另有 3 笔未平仓；**三笔最后报价均早于全局末次观测日，状态为 `missing_unknown`**。机器报告的 985,716.36 元权益及 2.37% 最大回撤只是按最后已知价的临时估值，不能作为收益、风险或策略有效性结论。稀疏抽样缺少全市场逐日完整行情、历史名称／公司行动和可持续估值；这里验证的是共享资金执行流程，**尚未完成 5,000+ 全市场单仓验收**。本引擎已编入 Qt 6.11.2 的 `PPTrader.exe`，本轮经隔离 C++ 组合探针调用同一引擎；可见 GUI 的组合入口尚未接线，不称 UI 级组合回测通过。机器结果见 [单仓报告](../artifacts/limit-up-pptrader-backtest-2026-09-22/shared-capital-portfolio.json)。

## 结论与边界

二板 `tick_second_board` 和三板 `tick_third_board` 已作为 PPTrader 内置原始 Tick 策略登记，可从现有策略目录选择。本轮用 PPTrader 的 `BatchBacktestService → BacktestEngine` 执行，不再以独立 Python 交易模拟代替应用回测。

2026-07 至 2026-09 的分层抽样中，**58 个去重事件窗口全部完成 PPTrader 严格数据准入与逐股回测**：58 个买入信号对应 58 笔买入，入场当日 15:00 收盘封板 13 次。54 笔由策略条件卖出，另 4 笔在样本结束时由引擎强制平仓；13 次封板中 11 次对应策略卖出，2 次对应强平，不能把强平当作真实可卖成交。T+1 违规为 0。

这部分逐股结果只是检验策略已接入、因果时间、原始数据与执行链路的**研究抽样**，不是 5,000+ 股票全市场、共享资金仓或无偏胜率验收。抽样先按事前 09:35 因子选出候选，因此“13/58”不得推广为全市场封板率；也不证明收益、盘口排队成交、实盘可用或交易资格。本轮遵照用户要求不设置收益门槛，也不据此优化月收益。

## PPTrader 策略规则

- 只支持 A 股主板代码与原始 Tick；ST/退市名称由策略拒绝。隔离探针只有代码名，本轮样本先使用已有名称清单排除 ST/退市，仍缺历史身份的权威复核。
- 根据已经完成的交易日收盘价和连续封板数，将前日首板划为二板候选、前日连续两板及以上划为三板候选；前日最终封板时间分别不晚于开盘后 90/60 分钟。
- 目标日 09:35 前最低涨幅 1%、早盘最高价回撤不超过 3%，且信号前未触板；09:35 后只在低于理论涨停价的真实 Tick 发买入信号，默认最晚 10:00。单笔最高金额 5 万元、参与率不超过该笔成交量 1%、100 股整手。
- 次日 09:35 后仅在严格高于理论跌停价、且单笔成交量覆盖计划卖出量时发卖出信号。单笔容量是保守简化模型，**不是逐笔部分成交或真实排队撮合**；部分持仓可能在样本结束时仍未触发策略卖出。引擎此时会做估值用强平，报告单列。
- 策略直接输出“入场日结果已知”和“入场日收盘封板”观察事实，不依赖次日是否卖出，避免强平掩盖封板命中。观察事实是信号层信息，不冒充成交回报。
